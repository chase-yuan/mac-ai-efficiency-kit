## 🚀 极速安装方式（直接扔给你的 AI，摩擦力为零）

**如果你在使用 Antigravity / Codex / Claude Code / Cursor 等 AI 助手：**
直接将本文件夹拖入你的 AI 聊天窗口，发送以下这句话即可：

> **「请阅读并执行本目录下的 `SETUP.md`，把这些技能与规范全自动安装到我的电脑上。」**

你的 AI 助手会自动感知你的 Mac 环境、创建目录并完成配置，并在 10 秒内向你汇报安装结果！

如果你希望直接在 Mac 终端中手动安装，只需在当前目录运行：
